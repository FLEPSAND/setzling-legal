Questions fréquentes

La pause n’apparaît pas.

Vérifie dans les réglages de Setzling que Temps d’écran est autorisé et que la pause est activée, et que des apps sont bien choisies pour la plante. Dans Réglages → Temps d’écran sur ton iPhone, Temps d’écran doit être activé.

Après « Ouvrir un instant », aucune notification n’arrive.

Autorise les notifications de Setzling dans Réglages → Notifications → Setzling. Sans notifications, tu peux aussi ouvrir Setzling toi-même, la pause démarre alors dans l’app.

Pourquoi je ne vois pas les noms des apps dans Setzling ?

Apple ne transmet les apps choisies à Setzling que sous forme chiffrée. Cela protège ta vie privée. Tu vois les noms dans la liste de sélection d’Apple.

Comment avoir plusieurs plantes ?

Avec Setzling Pro, touche « Nouvelle plante » dans le jardin, choisis un groupe comme Réseaux sociaux ou Jeux, une plante et les apps qui vont avec. Chaque plante pousse ensuite selon le temps passé dans ses propres apps.

Comment résilier Setzling Pro ?

Les abonnements se gèrent via Apple : Réglages → ton nom → Abonnements → Setzling Pro. Ou dans Setzling, sous Réglages → « Gérer l’abonnement ».

J’ai acheté Pro, mais il n’est pas actif.

Touche « Restaurer » sur la page Pro. Setzling demande alors tes achats à Apple.

Comment supprimer complètement le blocage ?

Désactive la pause dans Setzling ou supprime l’app. Avec l’app, tous les blocages disparaissent.
